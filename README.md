Onyx is an enterprise-grade financial fraud detection frontend platform featuring real-time risk calculation, multi-hop mule account network graph analysis, dynamic plain-language threat explanations, and interactive 3D holographic risk visualization gauges.

---

## ✨ Features

- **3D Holographic Risk Gauges**:
  - **Horizontal Cylindrical Risk Bar**: Multi-stop 3D gradients, specular glass reflection sheen, animated shimmer sweeps, and leading jewel sphere.
  - **Circular Metallic Risk Gauge**: Beveled metallic bezel, convex glass dome, and 100% lockstep frame-by-frame on-load fill and counting ticker.
- **Dynamic Plain-Language Explanations**:
  - Automatically translates complex behavioral signals (velocity surges, pass-through mule patterns, phishing signatures) into simple, clear words for everyday users.
  - Tailors recommendations, badges, and action buttons based on risk levels (High, Medium, Safe).
- **Interactive Cyber-Node Background Canvas**:
  - Continuous perpetual drifting motion with harmonic sinusoidal oscillation and cursor-reactive laser proximity physics.
- **Mosaic Curtain Page Transition Grid**:
  - GSAP-powered modular pixelated grid page reveal animations.
- **Dual Portal Authentication**:
  - Seamless 3D flip card toggle between **Customer Portal** and **Bank Officer Portal**.
- **Bank Officer SOC Investigation Dashboard**:
  - Live filterable dispute queues, autonomous account freezing simulations, multi-hop transaction trails, and linked account network graphs.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/soumainchoudhary/Onyx-Frontend.git
cd Onyx-Frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
